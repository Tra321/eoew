## 🍱 苍穹外卖（Sky）

苍穹外卖是一款外卖点餐系统，集成用户端与商家管理端。用户可以浏览商品、下单和支付；商家可以管理商品、订单与店铺。

### 技术栈

| 层次 | 技术 |
| --- | --- |
| 前端 | Vue |
| 后端 | Spring Boot |
| 缓存 | Redis |
| 接口文档 | Swagger |
| 认证 | JWT |
| 数据库 | MySQL |

### 主要功能

- **用户端**：商品浏览、在线下单、订单支付。
- **商家端**：商品管理、订单管理、店铺管理。

### 运行说明

以下为仓库现有说明提供的基本启动流程；具体脚本位置、配置文件名与启动入口以 `Sky` 目录内的工程文件为准。

1. 克隆本仓库。
2. 找到并导入项目对应的数据库 SQL 脚本，创建 MySQL 数据库。
3. 修改后端配置文件中的数据库连接等必要配置。
4. 启动 Redis 服务。
5. 根据工程中的构建配置启动后端及所需前端服务。
6. 原仓库文档提供的访问地址为 `http://localhost:8080`；实际端口请以配置文件为准。
